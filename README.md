# ewc - epub-wordcount  
Written May 2026 by Sam Castle  
### CURRENT VERSION  
0.2.0

### PURPOSE  
determines the number of words in an epub file

### INSTALL 
 1) download the repo
 2) (optional) symlink `ln -s /path/to/ewc /dir/in/your/path/ewc`  

### USAGE  
`ewc <flags> <file>`
